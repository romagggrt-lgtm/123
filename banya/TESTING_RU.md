# Проверка Z_Banya 1.0.1

Первичные доказательства находятся в `banya/live-qa/`, сводка выпуска — `dist/Z_Banya_1.0.1.report.json`. Результат игрового прогона принимается только из `latest.json` со статусом PASS. Дистрибутив копирует именно `tested-plugin.jar` из этого прогона и сверяет SHA256; QA-плагины в него не входят.

## Логика и сохранения

`mvn -f banya/pom.xml verify`: 23 теста. Помимо прежних проверок участка, строительства, предмета, эффектов, журналов и сохранности вещей, добавлены проверки компактной единственной парной, размеров и поворотов области, перехода на MASTER, интервала повторения записи, остановки снаружи, паузы при загрузке RP, возобновления после загрузки, остановки прежнего канала при его смене и удаления полного старого здания из JSON без нового поля layout.

В журнале 1.0.0 поле layout отсутствует. Значение 0 сохраняет исходные границы, внутреннюю область, бочку и декор большой бани. Новые постройки получают layout 1. Уменьшение глобальной модели не обрезает территорию старого журнала.

MockBukkit не является настоящим Minecraft. В явно помеченном тестовом адаптере заменены загрузка чанков, рамки и отправка звуков; сохранены обходы отсутствующих декоративных состояний и ошибки обновления BlockState в MockBukkit. Само воспроизведение, настоящие чанки, рамки, полноценное употребление еды и обновление старого плагина проверяются отдельным прогоном Paper.

`python tools/test_banya_pack.py`: пять проверок прежнего RP 1.09, всех новых моделей, текстуры, OGG, контрольных сумм и сохранения старых ресурсов. В 1.0.1 звуковые и графические файлы не менялись: выпуск использует тот же RP 1.09.

## Настоящее обновление и игра

Изолированный workflow скачивает официальный Paper 1.21.11 build 132 с проверкой SHA256 и использует Java 21. Работают два клиента протокола и официальный немодифицированный Minecraft 1.21.11 в Xvfb/Mesa. Выполняются три полных запуска сервера:

1. Настоящий прежний JAR 1.0.0 создаёт большую баню и сохраняет семь алмазов в её бочке.
2. Устанавливается новый JAR 1.0.1. Проверяются загрузка старого журнала с его полными границами, отказ удаления при вещах в бочке, затем полное восстановление старой территории после освобождения контейнера. Новый плагин создаёт маленькую парную 7×7 с областью крыши 9×9, тремя рамками и одной вкусняшкой. Проверяются приватный звук, его повторение и остановка, употребление еды при полном голоде, пять эффектов и шесть сердец поглощения.
3. Новый сервер повторно перезапускается. Проверяются сохранение компактной бани, отсутствие повторного появления еды и рамок, защита вещей в бочке при удалении, восстановление всех исходных блоков и сохранность соседнего обычного сундука.

Звуковые пакеты проверяются отдельно: только получателю внутри, тип entity_sound_effect, канал MASTER, entityId самого получателя. Это подтверждает привязку к движущемуся посетителю. Внешний клиент не должен получать записи.

## Проверка реального аудиосигнала

В обычном Minecraft тестовый ползунок «Окружение» выставлен в 0, общая громкость — в 1. OpenAL Wave File Writer записывает реальный выход звукового движка клиента. После входа камера остаётся в парной дольше полной длительности записи.

`tools/banya_audio_check.py` сравнивает записанный сигнал с оригинальным OGG через нормированную корреляцию после одинакового преобразования в mono 8 kHz. Для PASS необходимы корреляция выше 0.65 и RMS выше 0.02. Метрики сохраняются в `client-audio.json`; `client-ambient-captured.ogg` содержит реальный записанный фрагмент. Это проверяет декодирование и слышимый по амплитуде сигнал самого клиента, а не только отправку сетевого пакета. Копия делается до отключения от сервера: сброс ресурс-пака иначе перезапускает устройство и перезаписывает WAV.

Субъективное прослушивание через физические колонки не выполняется. Фактическая громкость на компьютере игрока зависит также от общей громкости Minecraft, системного микшера и устройства вывода.

## Визуальная проверка и пределы

PNG в `live-qa/` — снимки настоящего клиента. По ним проверяются компактная парная без комнаты отдыха, полки, печь, котёл, окна, фонари, рамки и прежняя объёмная модель еды. Снимки просмотрены перед упаковкой выпуска.

Не проводился длительный нагрузочный тест со всеми 64 банями или запуск со всеми сторонними плагинами вашего сервера одновременно. Плагин использует обычный Paper API, отдельные ключи данных и защищённые журналы; внешние изменения через WorldEdit могут потребовать разрешения конфликта, чтобы не затереть чужую работу.

Офлайн-клиент QA может выводить ошибки онлайн-профиля/Realms и системного диктора. Старый ресурс-пак содержит прежнее предупреждение particle у z_verity:item/verity_box. Исторические неудачные проверки сохранены в истории Git и не считаются PASS итогового выпуска.
