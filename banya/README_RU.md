# Z_Banya 1.0.2

**Paper 1.21.11, Java 21.** Компактная деревянная парная: корпус 7×7, область со свесом крыши 9×9. Полки в два уровня, печь, котёл, фонари, рамки с вёдрами, пар, оригинальный звук и объёмная «Вкусняшка Тома». Клиентские моды и дополнительные серверные плагины не требуются.

## Что изменилось

- Один игрок может создать несколько бань с разными названиями.
- Бани создаются и удаляются по имени, например `1`, `2`, `Парная`, `VIP_баня`.
- Активную баню разрешено разбирать и перестраивать обычным способом.
- Удаление восстанавливает исходную территорию, даже если часть блоков сломана, заменена или внутри поставлены новые блоки.
- Вещи из контейнеров при удалении сохраняются в центре бывшей бани: без исчезновения по времени, с защитой от огня и без движения. Координаты выводятся в чат.
- Названия, изменения и данные возврата вещей сохраняются после перезапуска.

## Обновление

1. Полностью остановить сервер.
2. Удалить прежний JAR плагина из `plugins/` и положить новый `Z_Banya-1.0.2.jar`. Оставить только одну версию JAR. Сохранить папку `plugins/Z_Banya/` вместе с журналами.
3. Запустить сервер и выполнить `/zbanya list`.

Прежним баням без имени автоматически присваиваются свободные номера. Имена сразу сохраняются на диск. Ограничение «одна баня на игрока» снято; старый параметр `banya.max-per-player` удаляется из конфига автоматически. Общий предел по умолчанию — 64 бани, он настраивается через `banya.max-total`.

Графика и звук совместимы с прежним **Z_Server_Pack 1.09**. Строки `server.properties` остаются прежними. Полный архив содержит этот RP, отдельный RP бани, исходники и инструкции.

## Команды

Все команды управления требуют `zbanya.admin`, по умолчанию доступного OP.

```text
/zbanya set 1
/zbanya set 2
/zbanya remove 1
/zbanya remove 2
```

| Команда | Действие |
|---|---|
| `/zbanya set <имя>` | Найти участок поблизости от игрока и создать именованную баню. |
| `/zbanya remove <имя>` | Удалить именно указанную баню; расстояние до неё не ограничено. |
| `/zbanya list` | Показать существующие названия и координаты. |
| `/zbanya sound` | Перезапустить кастомную запись, находясь внутри бани. |
| `/zbanya status` | Показать версию, определение входа, канал, громкость и статус RP. |
| `/zbanya reload` | Перечитать настройки. Также доступно консоли. |

Имена уникальны на всём сервере, регистр не учитывается. Допустимы 1–32 буквы, цифры, `_` и `-`, без пробелов. Имена подставляются при автодополнении `remove`. После завершения удаления имя освобождается и может использоваться снова. Если указанное имя не найдено, соседняя баня не удаляется.

Для совместимости `/zbanya set` без имени присваивает следующий свободный номер, а `/zbanya remove` без имени по-прежнему удаляет ближайшую баню в пределах 20 блоков.

## Ручное разрушение и удаление

Обычные игроки могут ломать и ставить блоки активной бани, взаимодействовать с её рамками и забирать вещи. Отдельного разрешения для этого не нужно. При строительстве и удалении рабочая область временно блокируется до завершения операции.

Изменённые рамки не создаются заново после загрузки чанка или рестарта, поэтому разборка не даёт бесконечные вёдра. Если разобрать каменку, прекращаются её пар и музыка. При восстановлении каменки эффекты снова доступны.

Ручная разборка сохраняет запись бани и её имя. Команда `/zbanya remove <имя>` завершает удаление и возвращает исходное состояние территории. **Все изменения внутри сохранённой области бани отменяются**, включая поставленные игроками блоки. Соседняя область и другие бани не затрагиваются. Для новых бань сохраняется весь объём 9×9, включая изначально пустые клетки. Прежние журналы сохраняют оригинальную записанную землю; неизвестные пустые клетки старой постройки очищаются как исходный воздушный объём.

`restore-terrain-on-remove: false` оставляет подготовленную часть ниже пола; по умолчанию включено полное восстановление. Пересечения двух бань запрещены. `allow-overlap: true` убирает дополнительный зазор, но сами области всё равно не пересекаются.

### Вещи из контейнеров

Перед очисткой контейнеров их содержимое с полными данными предметов записывается в журнал. У двойного сундука учитывается каждая половина отдельно. После восстановления земли вещи появляются над центром бывшей бани; сообщение показывает мир и координаты. Их можно подобрать обычным способом.

Такие предметы не исчезают по времени, не горят и не падают в ямы. Во время записи результата они временно закрыты для подбора; после завершения автоматически доступны. Повторное восстановление операции не создаёт уже выданные предметы заново. Проверены сохранение метаданных и перезапуск сервера после удаления.

Не взятая оригинальная вкусняшка удаляется вместе с баней. Вкусняшка, которую игрок уже забрал и вернул в контейнер, сохраняется как его вещь. При обычном ручном разрушении действуют правила дропа Minecraft.

## Поиск участка

Поиск конечный и распределён между тиками. Центр новой бани находится в пределах 5–20 блоков от позиции игрока при запуске команды. Вход направлен к этой позиции. Проверяется вся область постройки и фундамента, загруженные чанки, граница мира и отсутствие сущностей.

Нужен открытый участок в обычном мире, свободная область 9×9 до 8 блоков над поверхностью. Допускается перепад земли в один блок. Вода, обрывы, дома, подземные сундуки, механизмы и другие бани исключаются. В Незере и Крае строительство отключено. Если места нет, выводится сообщение; существующая застройка не сносится ради установки.

## Звук и RP

Использован именно приложенный файл `баня, плагин.MP3`, преобразованный в OGG Vorbis и нормализованный примерно до −14 LUFS. Длительность — около 10 секунд, событие `zbanya:ambient`.

Каждый посетитель слышит запись отдельно. Она следует за самим игроком, использует общую громкость и повторяется после полного окончания. Выход, телепортация, смерть, выход с сервера и удаление бани прекращают звук. После загрузки серверного RP воспроизведение внутри возобновляется.

```yaml
sound:
  enabled: true
  sound-key: "zbanya:ambient"
  category: "MASTER"
  volume: 1.0
  pitch: 1.0
  stop-on-exit: true
```

Для проверки войдите внутрь и выполните `/zbanya sound`. Если тихо, проверьте общую громкость Minecraft и системный микшер; `/zbanya status` покажет включение звука и состояние серверного RP. Для прямой проверки ресурсов доступна команда `/minecraft:playsound zbanya:ambient master @s ~ ~ ~ 1 1`.

RP подключается через пять строк из `server.properties.txt`, с прямой ссылкой на ZIP. Сам плагин не отправляет дополнительных пакетов. На нашем сервере используется общий `Z_Server_Pack_1.09.zip`; отдельный `Z_Banya_ResourcePack.zip` предназначен для сервера без общего пака. Для объединения копируется только `assets/zbanya/`. Сервер полностью перезапускается после замены JAR или настроек `server.properties`.

## «Вкусняшка Тома»

Объёмная модель с собственной текстурой и тремя мухами. В руке и у выброшенного предмета мухи двигаются, во время еды смена кадров приостанавливается.

Для каждой новой бани один раз рассчитывается шанс 50%. При успехе появляется одна вкусняшка в бочке у входа. Входы, открытие бочки и перезапуск не создают новые предметы. Основа — хлеб с собственными данными; переименование обычного хлеба не даёт эффектов. Есть можно и при полном голоде.

| Эффект | Уровень | Длительность |
|---|---|---|
| Регенерация | II | 10 секунд |
| Поглощение | III — шесть жёлтых сердец | 120 секунд |
| Сопротивление | I | 60 секунд |
| Огнестойкость | I | 120 секунд |
| Тошнота | I | 8 секунд |

Эффекты выдаются после полного употребления, предмет расходуется. Ванильные эффекты золотого яблока у основы отсутствуют. Более сильные внешние эффекты обрабатываются обычными правилами Minecraft.

В конфиге настраиваются радиус, общий предел, скорость установки блоков, восстановление земли, звук, пар, шанс еды, количество и длительности эффектов. Значение длительности 0 отключает соответствующий эффект.

## Исходники и сборка

Проект включает Java-классы, `pom.xml`, `plugin.yml`, `config.yml`, оригинальный MP3, OGG, модели, текстуру, генератор ресурсов и проверки. Нужны JDK 21 и Maven:

```sh
mvn -f banya/pom.xml verify
```

Результат — `banya/target/Z_Banya-1.0.2.jar`. Версия автоматически включается в имя JAR при сборке; в установочном архиве используется такое же имя. Для пересоздания RP нужны Python 3, Pillow и FFmpeg/FFprobe:

```sh
python tools/build_banya_pack.py
python tools/test_banya_pack.py
```

Проверки на настоящем сервере и их ограничения описаны в `TESTING_RU.md`. Папку `plugins/Z_Banya/baths/` следует сохранять вместе с миром: она содержит названия, координаты и исходные состояния блоков для удаления.
