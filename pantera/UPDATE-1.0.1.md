# Обновление Z_Pantera 1.0.1

В 1.0.0 текстура частей ItemDisplay лежала в `textures/entity/`. Этот каталог
не входит в ванильный атлас предметов Minecraft 1.21.11. Геометрия загружалась,
но UV брали чёрно-фиолетовую текстуру ошибки. Обычная проверка наличия PNG это
пропустила. В 1.0.1 текстура перенесена в `textures/item/`, исправлены ссылки всех
частей и моргания, добавлена проверка реальных правил ванильного атласа.

Звук из вашего `1024.MP3` усилен примерно на **5,9 дБ** с компрессором и
ограничителем пиков. После декодирования OGG максимальный пик около **−1 дБFS**,
перегрузки нет. Длительность, скорость и высота тона не менялись. По умолчанию
используется категория `MASTER`, поэтому ползунок «Мирные существа» больше не
приглушает эту запись; общая громкость игры продолжает действовать.

Все части модели получают небольшой минимум блочного освещения, чтобы детали
шерсти и глаза оставались различимы ночью. Естественный более яркий свет сохраняется.
Таймер жизни, приручение, звук по клику, сердечки и следование сохраняют прежние правила.

## Как заменить 1.0.0

1. Остановите сервер.
2. Уберите старый JAR **только Z_Pantera 1.0.0** из `plugins/` и положите туда
   **один** `Z_Pantera_1.0.1.jar`. Существующую папку `plugins/Z_Pantera/`
   сохраните вместе с данными и настройками. JAR остальных плагинов остаются прежними.
3. В `server.properties` замените старый URL РП и SHA-1 строками из приложенного
   `server-properties.txt`. Новый общий пак называется
   **`Z_Server_Pack_1.05_Pantera_1.0.1.zip`**. Старый ZIP 1.0.0 исправлений не содержит.
4. Запустите сервер и переподключитесь, приняв обновлённый РП. Новый URL и SHA-1
   обеспечивают загрузку нового файла вместо прежнего кэша.
5. Для проверки выдайте яйцо: `/zpantera give ВашНик 1`. Осмотрите морду с зелёными
   глазами и нажмите ПКМ либо ЛКМ рядом с пантерой.

Общий пак по-прежнему содержит Shahed, Verity, Golda и Pantera, без SmpLore.
Прежние ресурсы Shahed/Verity/Golda сохранены побайтно. Раздача РП остаётся единственной,
через `server.properties`; Pantera не запускает дополнительных загрузок.

Новые параметры необязательно добавлять вручную: при их отсутствии в старом
конфиге применяются эти значения. Для явной настройки добавьте/измените ключи
в соответствующих разделах `plugins/Z_Pantera/config.yml`:

```yaml
model:
  minimum-block-light: 8
effects:
  sound-category: MASTER
  sound-volume: 1.0
```

Сохраните остальные ключи раздела `effects`, не создавайте второй раздел с тем же
именем. `minimum-block-light: 0` включает полностью естественное освещение.
`sound-category: NEUTRAL` возвращает управление через громкость мирных существ.
После изменения настроек выполните `/zpantera reload`.

54 проверки Java и 5 проверок РП/аудио проходят без ошибок и пропусков.
Проверка в Minecraft-клиенте в этой среде не выполнялась; подробности — `TESTING.md`.
