# Z_Nick 1.0.0

Требования: Paper 1.21.11, Java 21. Плагин не использует ресурс-пак и не изменяет UUID аккаунта. Установка: остановите сервер, поместите `Z_Nick-1.0.0.jar` в `plugins/` и включите сервер. Файл `plugins/Z_Nick/nicknames.yml` сохраняйте вместе с остальными данными сервера.

```
/znick set &#54DAF4н&#54C5EAи&#54B1DFк Player123
/znick remove Player123
/znick reload
```

В командах указывается настоящий ник или UUID игрока, уже известного серверу. Поддерживаются `&#RRGGBB`, цвета `&0`–`&f`, `&l`, `&o`, `&m`, `&n`, `&k`, `&r`. Разрешения: `znick.set`, `znick.remove`, `znick.reload`, `znick.admin`; OP по умолчанию имеет доступ. Параметры и сообщения настраиваются в `config.yml`.

Ник отображается в TAB, чате, сообщениях и над головой. Сторонние плагины могут самостоятельно отправлять текст, ссылки на профиль или изменять пакеты после Z_Nick; совместимость с их настройками нужно проверять на конкретном сервере. Серверные команды и права используют настоящий аккаунт. Отключение дублирующихся ников включено по умолчанию.

Исходники собираются Java 21 и Maven командой `mvn -f nick/pom.xml verify`.
