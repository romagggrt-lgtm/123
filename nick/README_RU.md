# Z_Nick 1.0.0

Требования: Paper 1.21.11, Java 21. Плагин не использует ресурс-пак и не изменяет UUID аккаунта. Установка: остановите сервер, поместите `Z_Nick-1.0.0.jar` в `plugins/` и включите сервер. Файл `plugins/Z_Nick/nicknames.yml` сохраняйте вместе с остальными данными сервера.

```
/znick set &#54DAF4н&#54C5EAи&#54B1DFк Player123
/znick remove Player123
/znick reload
```

В командах указывается настоящий ник или UUID игрока, уже известного серверу. Поддерживаются `&#RRGGBB`, цвета `&0`–`&f`, `&l`, `&o`, `&m`, `&n`, `&k`, `&r`. Разрешения: `znick.set`, `znick.remove`, `znick.reload`, `znick.admin`; OP по умолчанию имеет доступ. Параметры и сообщения настраиваются в `config.yml`.

Ник отображается в TAB, чате, сообщениях и над головой. Сторонние плагины могут самостоятельно отправлять текст, ссылки на профиль или изменять пакеты после Z_Nick; совместимость с их настройками нужно проверять на конкретном сервере. Серверные команды и права используют настоящий аккаунт. Отключение дублирующихся ников включено по умолчанию.

Исходники собираются Java 21 и Maven командой `mvn -f nick/pom.xml verify`.

## Проверка и совместимость

На отдельном сервере Paper 1.21.11 проверены установка, повторная смена, удаление, восстановление scoreboard-команды, консольные команды, офлайн-игрок, перезагрузка настроек и полный перезапуск. Отдельный прогон использует TAB 6.2.0, EssentialsX 2.22.0 и EssentialsXChat 2.22.0 с настройками по умолчанию. Проверка пакетов подтверждает передачу HEX-цветов, нового отображаемого имени, служебного имени профиля и сообщения в чате клиенту; ручная визуальная проверка всех клиентских ситуаций не проводилась.

LuckPerms использует обычные разрешения Bukkit; тест с конкретной установкой LuckPerms и индивидуальными настройками вашего сервера не проводился. TAB и другие плагины с нестандартными настройками или самостоятельной подменой пакетов могут потребовать отдельной проверки. Не используйте Z_Nick как гарантию анонимности: сервер, консоль, администраторы и другие плагины продолжают знать настоящий аккаунт, а сторонний плагин может вывести его в своём сообщении.
