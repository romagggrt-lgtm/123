# Z_Check 1.0.0

Для Paper 1.21.11 и Java 21. Установите один файл `Z_Check-1.0.0.jar` в `plugins/` и перезапустите сервер. Ресурс-пак и сторонние плагины не требуются. Папка `plugins/Z_Check/` хранит конфигурацию, активные проверки и журнал; сохраняйте её при обновлениях.

```text
/zc Steve       — вызвать онлайн-игрока на проверку
/zc Steve       — завершить проверку, в том числе если Steve уже вышел
/zcheck Steve   — то же действие
```

Права `zcheck.use` и `zcheck.notify` по умолчанию доступны OP; `zcheck.bypass` по умолчанию не выдаётся никому, включая OP. Для LuckPerms: `/lp user Ник permission set zcheck.use true`. Пользователь не может вызвать себя, если это не разрешено в `config.yml`.

Игрок может смотреть по сторонам и писать в чат. Движение, телепортации, действия с блоками, предметами и инвентарём, атаки и урон блокируются. Разрешённые команды и сообщения настраиваются. Проверки записываются сразу при изменениях и дополнительно с частотой `autosave-interval-ticks` (0 отключает повторную запись). Выход не приводит к наказанию; проверка сохраняется и восстанавливается при входе и после перезапуска. Уведомление по умолчанию получают инициатор, модераторы с `zcheck.notify` и консоль.

`audit.log` содержит время, UUID, исходное имя и UUID модератора. Прямое изменение координат другими плагинами в обход событий Paper не может быть гарантированно заблокировано. Для разрешённого переноса проверяемого человека другой плагин может получить сервис `ZCheckApi` через `Bukkit.getServicesManager().load(ZCheckApi.class)` и вызвать `moveCheckedPlayer(player, destination)` на главном потоке: он изменяет точку фиксации и возвращает результат телепортации. Обычные телепортации в обход этого API отменяются.

Сборка: `mvn -f check/pom.xml verify`. На Paper 1.21.11 проверены два запуска сервера, сохранение после выхода и перезапуска, реальное движение подключённого игрока до и после снятия, отмена урона; отдельные тесты проверяют права, команды, блоки, точку фиксации и целостность хранилища. Проверка с конкретными сборками LuckPerms/Essentials/WorldGuard не проводилась.
