EVRIONMC — ИКОНКА И MOTD ДЛЯ MINECRAFT JAVA

1. Иконка
Положи файл server-icon.png в корневую папку сервера, рядом с server.properties. Если там уже есть файл с таким названием, сохрани его копию и замени. Нужное имя — строго server-icon.png; размер подготовленной картинки — 64×64 пикселя.

2. MOTD
Открой server.properties. Найди существующую строку, начинающуюся с motd=, и замени её целиком одной строкой из файла motd-server-properties.txt. Не заменяй весь server.properties. Не добавляй переносы внутрь строки; последовательность \n в ней обозначает вторую строку MOTD. Последовательности \uXXXX нужны, чтобы цвета и русский текст корректно прочитались в Java.

Надпись «Версия 1.21.11» сохранена, как в исходном MOTD. Для выравнивания использованы размеры символов стандартного шрифта Minecraft 1.21.11. С другим шрифтом из ресурспака или модификации возможен небольшой сдвиг.

3. Запусти сервер заново и обнови список серверов в Minecraft. Картинка motd-preview.png — предварительный просмотр; в игре внешний вид может немного отличаться.

Надпись над MOTD (на твоём скриншоте «ЗАЛУПА») — имя записи, сохранённой в твоём клиенте, а не часть MOTD. Её меняют в Minecraft: выбери сервер → «Изменить» → «Имя сервера» → EvrionMC. Каждый игрок задаёт это имя у себя.
