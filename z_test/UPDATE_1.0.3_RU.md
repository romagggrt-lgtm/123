# Z_Test 1.0.3: попадание по душам

Выключите сервер и замените старый JAR Z_Test на `Z_Test-1.0.3.jar`. Данные плагина и мир Чистилища не удаляйте. Ресурспак и Z_Lor обновлять не нужно.

По видимой модели души можно попасть обычным ударом игрока. Урон наносится через стандартную атаку Minecraft; при гибели она по-прежнему оставляет осколок. Другие мобы не меняются. Команды проверки `/ztest souls status` и `/ztest souls spawn` сохранены.
