# Обновление Z_Gold 1.0.1 и одна загрузка общего ресурс-пака

## Что исправлено в JAR

- Удалены сообщения «Golda выдала … Всего …/15». Вопрос и кнопки остаются.
  Это действует и со старым config.yml, где messages.reward ещё содержит счётчик.
- Если ресурс-пак указан в server.properties, Z_Gold не отправляет ещё один.
- При самостоятельной раздаче Z_Gold отправляет пак один раз за вход.
  Ошибка загрузки не запускает цикл повторных запросов; задача от старой сессии
  не выполняется после переподключения.
- Счётчики, диалоги, инвентарь и опыт сохраняются как прежде; сброс не нужен.

JAR-файлы Shahed и Z_Verity и ZIP ресурс-пака не менялись.

## Почему возникало несколько экранов Mojang

В версии Shahed 1.03 отправка старого пака выполняется через 100 тиков после
входа (около 5 секунд), через setResourcePack. В Z_Verity 1.0.2 ещё один пак
добавляется через 120 тиков (около 6 секунд). В Z_Gold 1.0.0 свой запрос
происходил через 40 тиков. Вместе с настройкой server.properties получалось
несколько независимых запросов и перезагрузок ресурсов. Более старый пак Shahed
может заменить общий набор, в котором есть модель Golda.

Обновлённый Z_Gold сам не может остановить код уже установленных старых плагинов,
не вмешиваясь в их работу. Поэтому отключите раздачу в их конфигурациях.

## Порядок обновления

1. Полностью остановите сервер.
2. Замените старый JAR Z_Gold файлом Z_Gold_1.0.1.jar. Оставьте только одну
   копию плагина в plugins. Папку plugins/Z_Gold с сохранениями оставьте.
3. В КАЖДОМ из файлов:

   - plugins/Shahed/config.yml
   - plugins/Z_Verity/config.yml
   - plugins/Z_Gold/config.yml

   найдите существующий раздел resource-pack и установите эти два значения:

   ```yaml
   resource-pack:
     enabled: false
     prompt-on-join: false
   ```

   Остальные строки этого раздела и других разделов оставьте. Второй раздел
   resource-pack в том же файле добавлять не нужно. Для Z_Gold достаточно enabled;
   строка prompt-on-join нужна старым Shahed и Verity.

4. В server.properties оставьте ОДНУ общую ссылку и её SHA-1:

   ```properties
   resource-pack=https://raw.githubusercontent.com/romagggrt-lgtm/123/main/dist/Z_Server_Pack_1.05_Gold.zip
   resource-pack-sha1=ddfef4b8a51436ef085704b2e45407a06f1d4b7f
   require-resource-pack=true
   ```

5. Запустите сервер и переподключитесь. Примите ресурс-пак сервера.

Это тот же ZIP на базе 1.05: Shahed + Verity + Golda, без SmpLore. Перезаливать
его и менять SHA-1 для этого обновления не требуется. Лаунчер игрока менять не нужно.

Если установлен SmpLore и его resource-pack.properties содержит url, это ещё
один отправитель. Для общей раздачи только через server.properties оставьте
`url=` в plugins/SmpLore/resource-pack.properties и перезапустите сервер.

## Проверка

Выполнено 35 автоматических тестов, без ошибок и пропусков. Включены проверки
сохранности старых механик, скрытия счётчика со старой конфигурацией и отсутствия
дублирующихся запросов Z_Gold. Настоящий Minecraft-клиент здесь не запускался;
повторные запросы других установленных плагинов прекращаются после изменения
их конфигураций и полного перезапуска сервера.
