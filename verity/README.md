# Z_Verity 1.0.2

Отдельный плагин для Paper 1.21.11 / Java 21.
Shahed.jar заменять или пересобирать не требуется.

## Установка и обновление

1. Полностью остановите сервер.
2. Удалите прежние JAR Z_Verity из plugins, оставьте один Z_Verity_1.0.2.jar.
3. Установите общий Z_Server_Pack_1.05.zip. В нём сохранены все прежние
   файлы assets/shah, добавлены только ресурсы z_verity.
4. Запустите сервер. Известная старая официальная ссылка Verity и её SHA-1
   автоматически обновятся в plugins/Z_Verity/config.yml. Свою ссылку
   хостинга нужно обновить самостоятельно. Старые служебные объекты очищаются.
5. Получите новое яйцо: /give Ник verity. Прежние яйца тоже поддерживаются.

Для автоматического предложения ресурсов всем игрокам в server.properties:

```properties
resource-pack=https://raw.githubusercontent.com/romagggrt-lgtm/123/main/dist/Z_Server_Pack_1.05.zip
resource-pack-sha1=5c01b018a2cd391de078a216be19b1db06479bfd
require-resource-pack=true
```

Плагин умеет добавить тот же пак через современный API после отправки старого
пака Shahed; чужие серверные паки не сбрасываются. Если паками управляет другой
плагин, подключите ZIP через него и отключите resource-pack.prompt-on-join
в Z_Verity. Клиентские моды не требуются. Новый формат геометрии рассчитан на
клиент 1.21.11; старые клиенты через ViaVersion не поддерживаются.

## Использование

- /give Ник verity [количество], либо /zverity give Ник [количество].
- ПКМ яйцом по блоку: картонная коробка. В Survival тратится одно яйцо.
- ПКМ коробкой: шар плавно появляется за секунду; играет предоставленный звук.
- Следующее ПКМ по шару: Verity говорит Hello! и начинает следовать по пути
  перемещений игрока. Поворот камеры не задаёт позицию шара.
- Ещё одно ПКМ или удар после приветствия: смерть нажавшего игрока, сообщение
  с его именем и координатами, выпадение вещей без дублирования брони/offhand.
  Два пакета одного клика не считаются двумя отдельными нажатиями.
- До открытия коробку можно разбить ударом и вернуть яйцо вне Creative.
- /zverity clear — удалить все объекты Verity (оператор/консоль).
- /zverity pack — повторно запросить ресурс-пак.

Сфера имеет диаметр около 0.96 блока, лицо остаётся вертикальным. Она избегает
полных препятствий, следует по сохранённым точкам пути и не загружает чанки.
Это ограниченный обход препятствий; полного поиска пути по миру нет.
При выходе/смерти владельца, смене мира или далёком телепорте спутник удаляется.
Лимит по умолчанию 64 объекта, срок жизни 15 минут; настраиваются в config.yml.
