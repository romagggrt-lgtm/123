# Проверки Z_Verity 1.0.2 — 23 октября 2026

Сборка: Paper API 1.21.11, Java 21, Maven 3.9.11.

## Выполнено

- 30 JUnit-проверок: 8 проверок состояния/движения и 22 проверки событий/сущностей
  в MockBukkit 4.110.0. Ошибок, падений и пропусков нет. Скрипт сборки отдельно
  запрещает скрытые пропуски из-за неподдержанных методов MockBukkit.
- Коробка создаёт ровно один ItemDisplay и один Interaction; хитбокс центрирован.
- Появление, Hello!, защита от повторных пакетов ПКМ, последующее убийство ровно
  один раз, удаление пары после смерти.
- После поворота неподвижного игрока шар не обходит его. Следование за
  перемещающимся игроком, остановка на заданном расстоянии и ограничение скорости.
- Выпадение 32 алмазов, одной брони и предмета второй руки ровно по одному разу,
  включая случай keepInventory=true; двойного выпадения нет.
- Вызов звука один раз при открытии; звук не зацикливается при следовании.
- Разрушение коробки ударом и возврат одного яйца; отказ при занятом месте.
- Очистка при выходе, выгрузке мира, отключении плагина, потере визуальной
  сущности; старые объекты удаляются без удаления действующей пары.
- Лимит объектов; обычные /give и /minecraft:give не перехватываются.
- 15 структурных проверок пакета: JSON, пути текстур и item_model, OGG, SHA-1
  во всех новых конфигурациях, запрет изменения ресурсов assets/shah.
- Предпросмотр строится из экспортированного JSON и PNG с поворотами элементов
  и z-buffer. Это не аналитически нарисованный круг: рендерятся 3456 плоских
  граней фактической модели. В четырёх видах внутри силуэта нет отверстий.
  Радиус вершин 7.00478–7.02541 при целевом радиусе 7 модельных единиц.
- Текстура содержит одно лицо; для коробки создан собственный картон с лентой.
- Формат поворотов сверён с экспортёром Blockbench, commit
  ec0b2827104d0799c153bfb5f867579c0c44652f:
  js/formats/java/java_block.ts (формат >=1.21.11), js/io/format.ts
  (порядок ZYX, то есть Rz*Ry*Rx). Код/ресурсы Blockbench не включены в плагин.
- Модель и хитбокс не используют living entity, поэтому фантом не появляется.
  JAR Shahed и его Java/config-файлы не изменены.

## Границы проверок

MockBukkit не является запущенным Paper и не реализует движок коллизий.
В тестах явно используется фикстура пустого пространства и полных кубов.
Обычные стены и земля покрыты; все варианты форм блоков не эмулируются.
Сложный поиск маршрута через лабиринт не реализован: Verity идёт по следу
перемещений игрока с ограниченным обходом препятствий.

Официальная сборка Paper 1.21.11 найдена через API, но её двоичный файл и
клиент Minecraft недоступны: прокси возвращает CONNECT 403 с доменов
fill-data.papermc.io и piston-meta.mojang.com, в том числе при повторном
запросе с расширенными разрешениями. Живой Paper-сервер и Minecraft-клиент
не запускались. Нет заявления о проверенных FPS/TPS, звучании на клиенте,
получении пакета клиентом или совместимости с каждым сторонним плагином.

## Воспроизведение

`bash tools/build_verity.sh` собирает только Z_Verity, запускает тесты,
генерирует общий пакет, проверяет его и сохраняет предпросмотр.
Для генератора нужны Python 3 и FFmpeg; для предпросмотра — numpy и Pillow.
Сам плагин требует только Paper 1.21.11 и Java 21.
