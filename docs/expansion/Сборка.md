# Сборка исходников

Нужны JDK 21, Maven 3.9+ и доступ к репозиторию Paper. Из корня проекта:

```bash
mvn -f plast/pom.xml package
mvn -f tools-plugin/pom.xml package
mvn -f book/pom.xml package
mvn -f lor/pom.xml package
```

Для Z_AP сначала установите официальную библиотеку LibsDisguises 26.10.24 в локальный Maven-репозиторий, затем соберите проект:

```bash
curl -L https://github.com/libraryaddict/LibsDisguises/releases/download/v26.10.24/LibsDisguises-26.10.24-Github.jar -o LibsDisguises.jar
mvn install:install-file -Dfile=LibsDisguises.jar -DgroupId=me.libraryaddict.disguises -DartifactId=libsdisguises -Dversion=26.10.24 -Dpackaging=jar -DgeneratePom=true
mvn -f ap/pom.xml package
```

Готовые JAR находятся в `target` соответствующего проекта. Для воспроизводимой сборки общего пакета нужна Python-библиотека Pillow; скрипт `python3 tools/build_expansion_pack.py` берёт входной `dist/Z_Server_Pack_1.12.zip` и обновлённые ресурсы из `tools/expansion-assets`. После любых изменений содержимого пересчитайте SHA-1 нового ZIP и настройте Z_AP на тот же хэш.
