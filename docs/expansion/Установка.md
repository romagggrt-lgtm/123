# Установка обновления

Для Paper 1.21.11 и Java 21. Остановите сервер. Замените старые JAR плагинов Z_Lor, Z_Book и Z_AP новыми версиями; не оставляйте одновременно два файла одного плагина. Добавьте новые A_Tools и Z_Plast в папку `plugins`. Папки данных существующих плагинов сохраняйте. Запустите сервер и проверьте журнал на ошибки.

Общий ресурс-пак `Z_Server_Pack_1.13.zip` содержит прежние ресурсы из версии 1.12, новую модель огненного шара, страницу, войдометр и базовую модель пластинки. В `server.properties` укажите доступную игрокам прямую ссылку на этот ZIP и его SHA-1:

```properties
resource-pack=https://raw.githubusercontent.com/romagggrt-lgtm/123/feature/z-expansion-2026-11/dist/Z_Server_Pack_1.13.zip
resource-pack-sha1=aaa84ff81c779ea8a2074aceb61f138be1675a24
require-resource-pack=true
```

После изменения `server.properties` нужен перезапуск. Z_AP автоматически обновляет хэш с прежнего стандартного значения; если в `plugins/Z_AP/config.yml` задан другой собственный `ui.server-pack-sha1`, обновите его вручную. Ресурс-пак должен быть включён у игрока.

# Пластинки

Z_Plast отдельно добавляет небольшой динамический звуковой пак и не заменяет общий серверный пак. На сервере должны быть установлены `ffmpeg` **и** `ffprobe`; для загрузки плагин запускает обе программы. По умолчанию загрузка выключена, потому что внешний адрес ещё неизвестен. Откройте отдельный TCP-порт в панели хостинга/фаерволе, затем в `plugins/Z_Plast/config.yml` укажите его и доступный игрокам адрес:

```yaml
web:
  bind-address: 0.0.0.0
  port: 8765
  public-url: 'http://АДРЕС_СЕРВЕРА:8765'
```

Пример с обратным HTTPS-прокси: `public-url: 'https://music.example.org'`, прокси должен пересылать `/upload/` и `/pack/` на локальный порт 8765. Используйте HTTPS для доступа через интернет. Адрес `127.0.0.1` работает только на самом сервере и непригоден для игроков. Для изменений адреса, порта и конвертера нужен полный перезапуск сервера.

`/zbox` → «Загрузить» → открыть ссылку в браузере → выбрать MP3. Ссылка одноразовая и действует 10 минут по умолчанию; файл конвертируется в моно OGG для пространственного звука. Игроку потребуется принять дополнительный звуковой пакет. Если пакет не принят, предмет всё равно будет выдан, но звука не будет. Каталог открывается через `/zbox`; ЛКМ выдаёт копию, ПКМ открывает управление. Удаление трека не удаляет уже выданные предметы.

Для собственной картинки пластинки нарисуйте прозрачный PNG 16×16 или 32×32 и положите его в `assets/zplast/textures/item/record.png` основного пака. В `assets/zplast/models/item/record.json` замените `minecraft:item/music_disc_13` на `zplast:item/record`; `assets/zplast/items/record.json` уже ссылается на модель. Пересоберите ZIP, обновите его URL и SHA-1 в `server.properties` и `ui.server-pack-sha1` в конфигурации Z_AP. По умолчанию используется ванильная картинка, чтобы пользователь мог нарисовать свою.

# Команды

* `/zt set sharpness 5` — создать жителя-библиотекаря с книгой «Острота V», возле игрока; можно также указать взглядом свободный твёрдый блок в пределах пяти блоков. Уровень продажи ограничен ванильным максимумом.
* `/zt enchanted sharpness 100` — наложить остроту 100 на предмет в основной руке. Можно указывать другие имена через Tab. `/zt reset` снимает зачарования с предмета в руке.
* `/zbook give book`, `/zbook give redus_flimano`, `/zbook unlock` — получить книгу, получить страницу и изучить все заклинания в книге в руке. После выбора заклинания в книге примените его ПКМ; перезарядка «Редус Флимано» по умолчанию 40 секунд.
* `/lore give @s stationary_voidometer` — получить стационарный войдометр. Для крафта положите переносной войдометр в центр, компаратор справа, стеклянную панель слева, редстоун сверху и снизу, железные слитки по четырём углам. ПКМ по прибору либо по соседним кнопке/рычагу показывает высоту Войда Энда.
* Четыре кристалла Энда на обсидиане/бедроке вокруг одного пустого блока создают портал. Поддерживаются крест и четыре угла вокруг центра. Через 20 минут портал и эти кристаллы исчезают с визуальным взрывом; блоки основания сохраняются. При проходе ищется безопасное место на дальних островах Энда.
* Z_AP: «Инструменты и регионы» → «Книга заклинаний», «Жители и чары» или «Пластинки». Доступ также зависит от разрешений соответствующих плагинов.

В этой версии для удара по скрипуну используется **осколок аметиста**. Если под аметистовым кристаллом подразумевался другой предмет, правило нужно уточнить.
