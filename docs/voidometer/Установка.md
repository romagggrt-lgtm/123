# Исправление стационарного войдометра — Z_Server_Pack 1.14

Пак основан на версии 1.13. Сохранены все прежние текстуры, модели и звуки; изменены освещение модели стационарного войдометра и описание версии пака. У прибора появляется постоянная визуальная яркость, но окружающие блоки он не освещает. Плагины переустанавливать не нужно.

Остановите сервер и замените существующие строки в `server.properties`:

```properties
resource-pack=https://raw.githubusercontent.com/romagggrt-lgtm/123/feature/z-server-pack-1.14/dist/Z_Server_Pack_1.14.zip
resource-pack-sha1=492743d50661ca92451b85848acd9162d3a2204c
```

`require-resource-pack` оставьте в нужном вам состоянии. Чтобы дизайн Z_AP продолжал работать, в существующем разделе `ui:` файла `plugins/Z_AP/config.yml` замените значение строки `server-pack-sha1` на новый хэш:

```yaml
  server-pack-sha1: '492743d50661ca92451b85848acd9162d3a2204c'
```

Не создавайте второй раздел `ui:` — измените строку внутри существующего. Затем запустите сервер и примите новый ресурс-пак в клиенте.

Проверка: обычный клиент Minecraft 1.21.11, стандартная гамма 0,5, непроницаемая тёмная комната. На `lighting-comparison.png` новая модель слева, старая — справа. Проверка использует QA-пак, включающий неизменённую модель из релизного ZIP и копию старой модели для сравнения.
