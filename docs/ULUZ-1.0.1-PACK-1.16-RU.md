# Z_Uluz 1.0.1 и ресурс-пак 1.16

Для Paper 1.21.11, Java 21 и PacketEvents 2.14.0. Остановите сервер, уберите `Z_Uluz-1.0.0.jar` из `plugins` и установите `Z_Uluz-1.0.1.jar`. Папку `plugins/Z_Uluz` и данные других плагинов сохраняйте. При захвате выбранный игрок видит цветную заставку: 0,15 с появления, 1,5 с показа и 1 с затухания. Декоративные буквы используют обфускацию; уведомление об администраторе в чат не отправляется.

`Z_Server_Pack_1.16.zip` сделан из общего пака 1.15. Он сохраняет посох и исправление стационарного войдометра и повышает минимальную яркость размещённых моделей сирены, сигнализатора, поглотителя и магнетитового ядра. Это визуальная правка: она не создаёт освещение в игровом мире. Светлые модели будут хорошо видны в темноте без fullbright.

В `server.properties`:

```properties
resource-pack=https://raw.githubusercontent.com/romagggrt-lgtm/123/feature/z-uluz-1.0.1-pack-1.16/dist/Z_Server_Pack_1.16.zip
resource-pack-sha1=e075a7af6b15af4f9a629250ee2568b86481d87b
```

В `plugins/Z_AP/config.yml`, если установлен Z_AP, укажите:

```yaml
ui:
  server-pack-sha1: "e075a7af6b15af4f9a629250ee2568b86481d87b"
```

Сохраните файлы, запустите сервер и примите ресурс-пак на клиенте. Для Z_Plast по-прежнему используются его отдельный звуковой ресурс-пак и Web/TCP-порт. Удалять ранее установленные версии Z_Book, Z_Lor, Z_Plast или остальные серверные данные для этой правки не нужно.
