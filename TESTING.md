# Проверки — 19 октября 2026

## Выполнено

- JDK 21 установлен отдельно от предустановленного JRE. SHA-256 архива проверена по официальному файлу поставщика; Maven 3.9.11 проверен по официальной SHA-512. TLS-проверка не отключалась.
- `bash tools/bootstrap-env.sh`: успешно проверены доступные инструменты.
- `bash tools/build.sh`: Maven BUILD SUCCESS с настоящим Paper API `1.21.11-R0.1-SNAPSHOT`, Java release 21. JAR создан, не подменён исходниками.
- Девять проверок `FlightMathChecks`: переход угла через 0°, отрицательные углы, ограничение максимальной дальности при высокой скорости, отсутствие превышения дальности после многократных шагов, границы и монотонность сглаживания взлёта. Это проверки используемых функций, а не эмуляция Paper.
- Девять структурных проверок ZIP: целостность, формат 75, JSON, item_model-ссылки, объёмные элементы и границы координат, текстурные ссылки, PNG, звуковые ссылки/OGG, отсутствие замены vanilla assets.
- Повторная генерация пакета дала одинаковую SHA-256. ZIP содержит собственные временные ресурсы, не модовые.

Maven Surefire не обнаруживает интеграционных тестов. Успех Maven не означает, что игровые сценарии прошли. Отдельные проверки запускаются `tools/build.sh` явно.
