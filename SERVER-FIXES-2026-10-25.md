Целевая среда из журнала: Paper 1.21.11 build 132, Java 21.

| Проблема | Причина | Исправление |
|---|---|---|
| 26 исключений InventoryCache при отправке команд | В JAR зашит возврат `Set`, в Paper метод возвращает `Collection` | Установить `InventoryCache_1.0.1.jar` |
| 8 watchdog-дампов Z_Gold | Синхронные запись/fsync/переименование на главном потоке, в том числе при выгрузке посторонних чанков | Установить `Z_Gold_1.0.2.jar` |

## Дополнение: SimpleClans получен и исправлен

Пользователь предоставил SimpleClans `2.19.2-05e7abc`. Готова точечная сборка
`SimpleClans_2.19.2-locale-fix.1.jar`: ACF определяет язык через публичный
`Player.getLocale()`, без чтения внутреннего поля NMS. Сохранены кэш и уведомления
о смене языка; остальной код команд и кланов не менялся.

Остановите сервер, замените старый `plugins/SimpleClans.jar` новым файлом,
сохраните папку `plugins/SimpleClans/` и базу данных. Одновременно должен быть
установлен только один JAR SimpleClans. Если два предыдущих исправления уже
установлены, повторно менять InventoryCache и Z_Gold не требуется. РП не меняется.

Инструкция, 11 новых тестов и исходники — в `simpleclans-fix/` и отдельных
архивах `dist/SimpleClans_2.19.2-locale-fix.1-*`. Первоначальный комплект
`Server-Plugin-Fixes_2026-10-25.zip` остаётся архивом только двух предыдущих
исправлений; SimpleClans распространяется отдельным файлом.

## Заменить два плагина

1. Остановите сервер. Сохраните резервные копии `plugins/Z_Gold/` и
   `plugins/InventoryCache/`.
2. Уберите из папки `plugins/` старые JAR **этих двух** плагинов: `InventoryCache.jar`
   и `Z_Gold_1.0.1 (1).jar` (или их фактические старые имена). Для каждого оставьте
   один новый файл из комплекта: `InventoryCache_1.0.1.jar`, `Z_Gold_1.0.2.jar`.
3. Папки конфигураций и данных сохраните. Старые наборы InventoryCache, резервные
   копии, состояние Golda и инвентарные журналы совместимы.
4. Запустите сервер. РП, настройки `server.properties`, Shahed, Verity и Pantera
   для этого исправления менять не требуется.
5. Проверьте обычный вход не-OP игрока, OP-команды `/dk save` и `/dk load`, один
   полный цикл Golda и полёт/перемещение через много выгружаемых чанков.

Подробности изменений — в `gold/UPDATE-1.0.2.md` и `inventorycache/README.md`
в архиве исходников. Сохранение Golda идёт в потоке `Z_Gold-Storage`; выдача золота
и запланированная смерть выполняются после подтверждения соответствующей записи.
Другие игроки и тики не ждут медленный fsync этого файла. На остановке ожидание
завершения записи ограничено тремя секундами. При ошибке диска новые операции
Golda приостанавливаются, а ошибка остаётся в журнале для администратора.

## Убрать лишний LuckPerms для Velocity

В журнале рабочий **LuckPerms 5.5.71 уже успешно загружен**. Второй установщик
прав не нужен. При остановленном Paper уберите, если они присутствуют:

```text
plugins/LuckPerms-Velocity-5.5.71.jar
plugins/.paper-remapped/LuckPerms-Velocity-5.5.71.jar
```

Это JAR для отдельного сервера-прокси Velocity, он не является Bukkit-плагином
и не должен загружаться Paper. Правильный Bukkit JAR LuckPerms и папку с правами
сохраните. Папку `.paper-remapped` целиком удалять не требуется.

## Остальные сообщения журнала

- Ошибка определения локали SimpleClans исправлена в отдельном JAR, указанном
  в дополнении выше. Установка только Golda/InventoryCache эту ошибку не исправляет.
- Essentials сообщает об отсутствии Vault: связанные с Vault префиксы/суффиксы
  и групповые функции недоступны. Это отдельная необязательная интеграция, а не
  причина найденных зависаний Z_Gold.
- `resource-pack-id missing`: сервер генерирует ID автоматически. Для явного
  стабильного ID общего пака можно добавить `resource-pack-id=17e36816-ac9c-57bc-8a02-d7a0221a689e`.
  URL и SHA-1 рабочего РП при этом менять не нужно.
- Уведомление о более новой версии Minecraft не требует менять версию сервера:
  исправления собраны именно под указанный Paper 1.21.11.

**48 тестов Z_Gold + 10 тестов InventoryCache**, без ошибок и пропусков.
Использованы JUnit, MockBukkit, настоящие временные файлы и управляемые задержки
дискового исполнителя. Воспроизведён исходный `NoSuchMethodError` из загруженного

долговечных записей, отсутствие преждевременной награды, ошибка диска, восстановление
инвентаря и отсутствие повторного восстановления старого снимка.

После получения SimpleClans отдельно выполнены **11 тестов его исправления**,
без ошибок и пропусков. Исходная ошибка `NoSuchFieldException: locale`
воспроизведена; исправленный класс проверен в изолированном загрузчике.
Проверено побайтовое сохранение остальных существующих файлов JAR, а также
всех полей и остальных методов изменённого класса.

Настоящий сервер Paper с набором всех установленных сторонних плагинов здесь не
запускался. Аппаратная скорость диска хостинга не измерялась. Исходный пользовательский
лог в публичные архивы не включён.
