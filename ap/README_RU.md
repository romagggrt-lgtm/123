# Z_AP 1.0.0

Панель администратора для Paper 1.21.11 и Java 21, без клиентского мода. Это меню-инвентарь Minecraft: приложенные изображения служили ориентиром по цветам и расположению, а не обещанием полноценного веб-интерфейса.

## Установка

1. Остановите сервер и положите `Z_AP-1.0.0.jar` в `plugins`. Зависимости панелей необязательны: отсутствующий плагин не мешает остальным разделам.
2. Для морфов отдельно установите Z_Morph 1.0.0 и его обязательные зависимости LibsDisguises 26.10.24 и PacketEvents 2.14.0 (ссылки находятся в инструкции Z_Morph).
3. Чтобы видеть иконки, используйте общий `Z_Server_Pack_1.10.zip`; он содержит файлы предыдущего пака 1.09 и отдельные иконки Z_AP. После загрузки пака на публичный прямой HTTPS-адрес используйте URL и SHA-1 в `server.properties`. Если используете опубликованную копию этого проекта:

```properties
resource-pack=https://raw.githubusercontent.com/romagggrt-lgtm/123/feature/z-ap-1.0.0/dist/Z_Server_Pack_1.10.zip
resource-pack-sha1=37416de556993401f254bd86aa0b39aa0b9acb2a
require-resource-pack=false
```

Если меняете ZIP, вычислите его новый SHA-1 и укажите прямую ссылку на **этот** ZIP. Настройки пака задаются в `server.properties`, не в папках плагинов. Без пака меню использует ванильные предметы.
4. Запустите сервер, выполните `/ap` и введите стартовый пароль `324657` в поле наковальни и нажмите на бумагу слева. Смените его в разделе «Настройки». Пароль виден при наборе в вашем поле наковальни; в чат и консоль он не отправляется. На диске хранится солёный BCrypt-хеш, не сам пароль.

После пяти неверных попыток доступ блокируется на 15 минут по UUID и сохраняется после перезапуска. Сессия по умолчанию длится 10 минут бездействия; она прекращается при выходе, отзыве права, смене пароля, `/ap lock` и отключении плагина. Настройки времени и блокировки находятся в `plugins/Z_AP/config.yml`, основные сообщения — в `messages.yml`. `/ap reload` перезагружает их и закрывает сессии.

## Команды и права

- `/ap` или `/zap` — вход / открытие панели.
- `/ap lock`, `/ap help`, `/ap reload` — закрыть сессию, справка, перезагрузка (для последней нужен `z_ap.reload`).
- `z_ap.use` — доступ к авторизации. Пароль **не выдаёт** прав.
- `z_ap.actions.*` — права на действия; отдельно доступны `z_ap.actions.gamemode`, `.morph`, `.kits`, `.nick`, `.vanish`, `.banya`, `.teleport`, `.summon`, `.players`, `.speed`, `.world`, `.regions`, `.worldedit`, `.moderation`, `.settings`. По умолчанию — OP.
- `z_ap.see_vanish` разрешает показ скрытых игроков. Без него отображаются только игроки, видимые администратору.

Пример LuckPerms: `/lp user Ник permission set z_ap.use true`, затем выдайте нужные права на действия. Встроенные проверки исходных плагинов тоже действуют: например, морфу нужен `zmorph.use`, никнейму — `znick.set` или `znick.remove`, бане — `zbanya.admin`, проверке — `zcheck.use`. Присланный InventoryCache 1.0.1 самостоятельно требует OP даже при наличии разрешений LuckPerms.

## Разделы

Панель даёт доступ к режиму игры, списку и профилям игроков с пагинацией и поиском, телепортациям, морфам с поиском и категориями, никам, Nevidimka, именованным баням, сохранению/загрузке инвентаря, времени/погоде/скорости, региону и WorldEdit. Загрузка инвентаря и опасные действия требуют подтверждения. InventoryCache 1.0.1 поддерживает только `/dk save <имя>` и `/dk load <имя>`, поэтому список и удаление наборов не имитируются; перед загрузкой сама установленная версия делает резервную копию и проверяет, что инвентарь не изменился во время операции.

В Nevidimka статус читается из метаданных, принадлежащих именно этому плагину. Z_Banya строит и удаляет собственные именованные бани; панель не копирует генератор. Список морфов берётся из подсказок установленного Z_Morph. Действия Z_RG/WorldEdit доступны только при соответствующем установленном плагине и его правах. Z_RG не был предоставлен, поэтому точную совместимость его версии необходимо проверить отдельно.

Телепортация требует уже загруженного чанка, границы мира и свободной точки с опорой. Отменённые другими плагинами телепортации не считаются успешными. Действия Z_AP не рассылают общих объявлений; сторонние плагины и аудит могут записывать или показывать свои сообщения.

## Сборка

Установите Java 21 и Maven и выполните `mvn clean verify` в каталоге исходников. BCrypt упакован внутрь JAR; Paper API остаётся внешним. Результат: `target/Z_AP-1.0.0.jar`.
