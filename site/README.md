# Zalupa SMP — оболочка сайта

Статический сайт: откройте `index.html` в браузере или запустите из этой папки `python3 -m http.server 8000`. Текст разделов находится в `index.html`; настройки оформления — в `styles.css`. Светлая и тёмная темы переключаются кнопкой в шапке, выбор сохраняется локально в браузере.

Иллюстрация `assets/zalupa-world.png` создана специально для этого макета. Лицензии шрифтов находятся рядом с ними в `assets/fonts`.
