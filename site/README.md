# Zalupa SMP — оболочка сайта

Статический сайт без сборки и платных сервисов. Откройте `index.html` в браузере или запустите из этой папки `python3 -m http.server 8000` и перейдите на `http://localhost:8000`.

В `index.html` находятся названия и временные тексты разделов, в `styles.css` — оформление и адаптация для телефонов, в `app.js` — переключение темы и подсветка меню. Переключатель сохраняет выбор на устройстве посетителя. В меню верхней панели ссылки ведут к соответствующим разделам этой же страницы. Декоративные квадратики на первом экране слегка поднимаются при наведении мыши.

Фоновая иллюстрация `assets/zalupa-world.png` создана специально для макета. Декоративные пиксельные предметы извлечены из общего ресурс-пака сервера Z_Server_Pack 1.16; осколок аметиста — стандартная текстура Minecraft 1.21.11 (источник: https://github.com/InventivetalentDev/minecraft-assets). Лицензии шрифтов Unbounded и Manrope расположены в `assets/fonts`.
